## 🔄 Volver a archivar

Si el sitio cambia, se regenera todo y el diff del PR muestra qué cambió:

```bash
cd "$(git rev-parse --show-toplevel)"
tmp=$(mktemp -d)
for u in $(curl -fsS https://how.nixfred.com/sitemap.xml | grep -o '<loc>[^<]*' | sed 's/<loc>//'); do
    f=$(basename "$u"); [ "$u" = "https://how.nixfred.com/" ] && f=index.html
    curl -fsSL "$u" -o "$tmp/$f"
done
python3 assets/upstream-site/html2md.py "$tmp" assets/upstream-site/how.nixfred.com https://how.nixfred.com/ "$(date +%F)"
curl -fsSL https://how.nixfred.com/install.sh -o assets/upstream-site/how.nixfred.com/install.sh
for f in CLAUDE.md CONSTITUTION.md LINEAGE.md hooks/session-end-backup.sh settings.fragment.json; do
    curl -fsSL "https://how.nixfred.com/seed/$f" -o "assets/upstream-site/how.nixfred.com/seed/$f"
done
```
