## 🛠️ Clonar un fork con su upstream

```bash
clone_fork() {  # <destino> <fork> <upstream-owner/repo>
    git clone -b personal "https://github.com/robert-flo/$2.git" "$1"
    git -C "$1" remote add upstream "https://github.com/$3.git"
    git -C "$1" remote set-url --push upstream DISABLE
}

clone_fork ~/Projects/nixbash PJ-LARRY-fo-nixbash nixfred/nixbash
```

El submódulo `nixfredOS/` se inicializa al clonar el vault con:

```bash
git clone --recurse-submodules https://github.com/robert-flo/PJ-LARRY-rf-playbook.git
# o, en un clon existente:
git submodule update --init --depth 1
git -C nixfredOS remote add upstream https://github.com/nixfred/nixfredOS.git
git -C nixfredOS remote set-url --push upstream DISABLE
```
