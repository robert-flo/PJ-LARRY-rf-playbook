# 🔁 Equivalencias: de Claude Code a cursor-agent

> [!NOTE]
> **Navegación:**
> * Siguiente: [[10.2 - Repositorios Upstream y Forks|Repositorios Upstream y Forks]]
> * Volver a: [[00 - Indice General (MOC)|Índice General]]

how.nixfred.com está escrito para Claude Code. Este playbook usa **`cursor-agent`** (Cursor CLI, instalado con `mise`). Esta tabla es la traducción que el agente aplica en cada capítulo. Las filas marcadas *"a verificar"* se confirman con evidencia en el capítulo indicado y se actualizan aquí.

## Comandos y opciones

| Claude Code (sitio) | cursor-agent (este playbook) | Estado |
|---|---|---|
| `curl -fsSL https://claude.ai/install.sh \| bash` | `mise use -g cursor-agent` (ya instalado) · `cursor-agent update` | ✅ (`cursor-agent --version` → `2026.10.01-e373342`) |
| `claude` | `cursor-agent` | ✅ |
| `/login`, login en el navegador | `cursor-agent login` · comprobar con `cursor-agent status` | ✅ Paso 0 |
| Alias `ccc` / `cccc` de nixbash (`claude --dangerously-skip-permissions [-c]`) | `cursor-agent --force` / `cursor-agent --force --continue` | ✅ Paso 0 (nixbash conserva los alias de Claude; no se usan) |
| `claude --dangerously-skip-permissions` ("danger mode") | `cursor-agent --force` (alias `--yolo`): permite todo salvo lo denegado explícitamente | ✅ (`--help`) |
| Modo auto (clasificador de seguridad) | `cursor-agent --auto-review` | ✅ (`--help`) |
| `claude --continue` / `-c` | `cursor-agent --continue` · `cursor-agent resume` (último chat) · `cursor-agent ls` (elegir) | ✅ (`--help`) |
| `claude -p` (no interactivo) | `cursor-agent -p` (`--output-format text\|json\|stream-json`) | ✅ (`--help`) |
| Plan mode | `cursor-agent --plan` / `--mode plan` | ✅ (`--help`) |
| `/model`, routing Opus/Sonnet/Haiku | `--model <id>`, `cursor-agent models`; Cursor elige modelo por suscripción | Cap. 18 |
| `claude-router` (hook `UserPromptSubmit`) | **No aplica**: enruta entre modelos de Anthropic con hooks de Claude Code. Se conserva el fork por si se porta | Cap. 18 |
| Sesión que sobrevive al terminal (tmux/herdr) | `cursor-agent persist` | Módulo herdr |

## Archivos y configuración

| Claude Code (sitio) | cursor-agent (este playbook) | Estado |
|---|---|---|
| `~/.claude/` (identidad + memoria) | Raíz que detecte `bun Tools/DetectEnv.ts` de nixfredOS para Cursor | Cap. 4–5, a verificar |
| `CLAUDE.md` del proyecto (`/init`) | `AGENTS.md` del proyecto y `.cursor/rules/*.mdc` | Cap. 2 y 11 |
| `~/.claude/CLAUDE.md` global | Reglas de usuario de Cursor / contexto global que deje nixfredOS | Cap. 11, a verificar |
| `--append-system-prompt-file` (constitución nixfredOS) | Sin flag equivalente: se carga como contexto vía `AGENTS.md`/rules (lo indica `nixfredOS/INSTALL.md` §7) | Cap. 5 |
| Hooks en `settings.json` | `~/.cursor/hooks.json` (hooks de Cursor). nixfredOS **no** los cablea en Cursor todavía (§6) | Cap. 21, a verificar |
| Skills `~/.claude/skills/` | Skills de Cursor (`~/.cursor/skills/`) | Cap. 17, a verificar |
| Subagentes | Subagentes de Cursor (`~/.cursor/agents/`) | Cap. 22, a verificar |
| Permisos en `settings.json` | `~/.cursor/cli-config.json` (`permissions`, `approvalMode`, `sandbox`) | Cap. 19 |
| `/statusline` | `statusLine` en `~/.cursor/cli-config.json` | Cap. 2 |
| MCP (`claude mcp`) | `cursor-agent mcp` · `~/.cursor/mcp.json` | Cap. 26 |

> [!WARNING]
> **Hooks always-on.** En Claude Code, nixfredOS activa el formato de respuesta, el bucle de memoria y la inyección de contexto por turno con hooks. Según su propio `INSTALL.md`, en Cursor obtienes la skill, los datos USER, Pulse y la carga de contexto en cada sesión, pero **no** los hooks always-on (están en su roadmap). No se escriben hooks de Claude en la configuración de Cursor: quedarían inertes.
