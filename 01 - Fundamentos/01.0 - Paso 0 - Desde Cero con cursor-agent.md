## 🎯 Objetivo

El capítulo original lo hace el humano a mano, porque todavía no hay IA. Aquí el humano tiene a `cursor-agent` desde el inicio, así que el agente ejecuta y explica, y el humano aprueba. Al terminar: `cursor-agent` arranca limpio, sin errores, en el modo de permisos elegido.

---

## 🔧 Pasos

### 1. Instalar el harness — ⏳

Original: `curl -fsSL https://claude.ai/install.sh | bash`. Aquí `cursor-agent` ya está instalado con `mise`:

```bash
command -v cursor-agent
cursor-agent --version     # 2026.10.01-e373342 el 2026-10-12
cursor-agent update        # para actualizar
```

### 2. El costo — ⏳

El original recomienda el plan de Claude de $100–200/mes. Aquí cuenta el plan de Cursor de la cuenta con la que se hace login. Anotar el plan y los límites relevantes.

### 3. Login — ⏳

```bash
cursor-agent login       # abre el navegador (NO_OPEN_BROWSER=1 para no abrirlo)
cursor-agent status      # debe mostrar la cuenta
```

### 4. Modo de permisos — ⏳

| Original (Claude Code) | cursor-agent | Qué hace |
|---|---|---|
| `claude` (modo auto) | `cursor-agent --auto-review` | Un clasificador ejecuta solo lo seguro y pregunta el resto. |
| `claude --dangerously-skip-permissions` | `cursor-agent --force` (`--yolo`) | Ejecuta todo salvo lo denegado explícitamente. Lo que usa Fred. |
| Modo manual | `cursor-agent` | Pregunta antes de cada acción (según `~/.cursor/cli-config.json`). |

Decisión: _pendiente_. El modo `--force` solo tiene sentido con backups (Capítulo 7).

### 5. Shell (nixbash) — ⏳ decisión pendiente

Original: `curl -sL https://raw.githubusercontent.com/nixfred/nixbash/main/install.sh | bash`.

> [!WARNING]
> **Revisado el 2026-10-12 en el fork `PJ-LARRY-fo-nixbash`:**
> - `install.sh` tiene fijo `NIXBASH_REPO="https://raw.githubusercontent.com/nixfred/nixbash/main"` y descarga de ahí el `.bashrc`, así que ignora el fork.
> - Reemplaza `~/.bashrc`. En Omarchy eso pisa el `.bashrc` actual (que carga los defaults de Omarchy y el bloque `try` con `TRY_PATH=/zt`).
>
> Opciones: no instalarlo (Omarchy ya trae bash con eza, bat, fzf, zoxide); instalarlo desde el fork tras un PR que haga `NIXBASH_REPO` configurable y que fusione en vez de reemplazar; o solo portar los alias que interesen.

### 6. Reiniciar y continuar la conversación — ⏳

```bash
cursor-agent --force --continue   # o: cursor-agent resume
```

### 7. Tailscale — ⏳

```bash
command -v tailscale || sudo pacman -S --needed tailscale
sudo systemctl enable --now tailscaled
sudo tailscale up
tailscale status
```

> [!NOTE]
> El original usa `curl -fsSL https://tailscale.com/install.sh | sh`. En Arch el paquete oficial es `tailscale` y el servicio `tailscaled` se habilita a mano.

### 8. Cuando algo falla: la IA arregla la IA

Pegar el error en `cursor-agent` y decir "arréglalo"; abrir una segunda sesión para destrabar la primera; o pedirle que lea este vault y compare con la máquina. Repetir hasta que `cursor-agent` arranque sin errores.
